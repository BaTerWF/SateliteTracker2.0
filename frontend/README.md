# Satellite Tracker 3D

3D-визуализация спутников Земли в реальном времени с использованием React, Three.js и React Three Fiber.

## Технологии

- **React 18** - UI библиотека
- **Three.js** - 3D-графика
- **React Three Fiber** - React рендерер для Three.js
- **React Three Drei** - Вспомогательные компоненты для R3F
- **Vite** - Сборщик frontend-приложений
- **Axios** - HTTP клиент для взаимодействия с API

## Структура проекта

```
my-satellite-app/
├── public/                  # Статические файлы

│   │   ├── client.js        # Настройка axios

│   ├── utils/               # Вспомогательные функции

```

## Установка

1. **Клонируйте репозиторий**
   ```bash
   cd SateliteTracker2.0/frontend
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения**
   ```bash
   cp .env.example .env
   ```
   Отредактируйте `.env` при необходимости:
   ```
   VITE_API_URL=http://localhost:8000
   ```

4. **Добавьте текстуры Земли**
   Поместите следующие файлы в `public/textures/`:
   - `earth_color.jpg` - Цветная карта Земли
   - `earth_bump.jpg` - Карта рельефа
   - `earth_specular.jpg` - Карта бликов

   Вы можете скачать текстуры из открытых источников или закомментировать загрузку текстур в `App.jsx` для использования базовых материалов.

## Запуск

**Режим разработки:**
```bash
npm run dev
```
Приложение будет доступно по адресу http://localhost:3000

**Сборка для продакшена:**
```bash
npm run build
```

**Предпросмотр сборки:**
```bash
npm run preview
```

## API

Приложение взаимодействует с REST API по следующим эндпоинтам:

### Спутники
- `GET /api/v1/satellites/` - Список всех спутников
- `GET /api/v1/satellites/{id}/` - Детали спутника
- `GET /api/v1/satellites/{id}/position/` - Текущая позиция
- `POST /api/v1/satellites/` - Создать спутник
- `PUT /api/v1/satellites/{id}/` - Обновить спутник
- `DELETE /api/v1/satellites/{id}/` - Удалить спутник

### Станции
- `GET /api/v1/stations/` - Список всех станций
- `GET /api/v1/stations/{id}/` - Детали станции
- `GET /api/v1/stations/{id}/visible_satellites/` - Видимые спутники
- `POST /api/v1/stations/` - Создать станцию
- `PUT /api/v1/stations/{id}/` - Обновить станцию
- `DELETE /api/v1/stations/{id}/` - Удалить станцию

## Функционал

- **3D-визуализация Земли** с вращением и текстурами
- **Отображение спутников** в реальном времени
- **Орбиты спутников** с линиями траекторий
- **Интерактивность** - клик на спутник для детализации
- **Сайдбар** со списком спутников и фильтрацией
- **Автоматическое обновление** позиций каждые 5 секунд
- **Камера** с зумом и вращением
